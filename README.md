Ecommerce Frontend
 
Aplicação desenvolvida em **Angular** para consumo da API do backend `ecommerce-backend`.  
Inclui funcionalidades de **CRUD de produtos**, autenticação e gerenciamento de usuários.
 
---
 
Tecnologias
 
- Angular 17+
- TypeScript
- HTML / CSS / Bootstrap
- RxJS
- Docker
 
---
 
 Estrutura do Projeto
 
src/
├─ app/
│   ├─ components/        → Componentes visuais (CRUD, login, etc)
│   ├─ services/          → Serviços que consomem a API backend
│   ├─ models/            → Interfaces TypeScript
│ └─ app.module.ts → Configuração principal
├─ assets/
├─ environments/
│ ├─ environment.ts
│ └─ environment.prod.ts
